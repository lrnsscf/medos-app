# MedOS

MedOS ist eine Lern-App für das Medizinstudium, kostenlos, für Mac und Windows. Auf dieser Seite lädst du MedOS herunter und findest die Hilfe.

## MedOS herunterladen

Klicke auf den Link für deinen Computer. Die Datei landet in deinem Download-Ordner.

**Welche Zeile ist meine?**

- **Mac:** Nimm die erste Zeile, sie passt für jeden Mac. Die beiden anderen sind etwas kleinere Dateien für einen bestimmten Chip. Welchen Chip dein Mac hat, steht im Apple-Menü  oben links unter **Über diesen Mac**.
- **Windows:** die letzte Zeile.

## MedOS installieren

**Mac:** Öffne die heruntergeladene Datei und ziehe MedOS in den Ordner **Programme**. Beim ersten Start meldet der Mac, dass er MedOS nicht überprüfen kann. Das ist normal, weil MedOS nicht aus dem App Store kommt. Du erlaubst MedOS einmal unter **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen**. [Schritt für Schritt mit Bildern →](docs/installation.md#macos)

**Windows:** Öffne die heruntergeladene Datei. Windows warnt beim ersten Mal mit „Der Computer wurde durch Windows geschützt“. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. [Schritt für Schritt →](docs/installation.md#windows)

Danach hält sich MedOS selbst aktuell: Gibt es eine neue Version, zeigt die App sie unten links an, und du installierst sie mit einem Klick.

## Gut zu wissen

MedOS ist noch in der Testphase (Beta). Es arbeitet mit deinen echten Vorlesungen, Notizen und Anki-Karten. Alles bleibt auf deinem Rechner und wird täglich gesichert. Manches ist noch nicht fertig. Wenn etwas hakt oder fehlt, klicke in MedOS unten links auf deinen Namen und dann auf **Problem melden**. Das kommt direkt bei uns an.
